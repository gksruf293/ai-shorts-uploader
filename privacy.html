Privacy Policy

Last updated: September 28, 2026

AI Shorts Uploader ("the tool") is a private tool used only by its operator to upload videos to the operator's own YouTube channels. This policy explains what data the tool accesses and how it is handled.

Data the tool accesses

  • Google account authorization: OAuth access and refresh tokens for the operator's own channels, with the scopes youtube.upload, youtube.readonly and youtube.force-ssl.
  • Channel information: the channel ID and title, read only to confirm that a video is being uploaded to the intended channel.
  • Content the operator uploads: video files, thumbnails, titles, descriptions, tags and comment text created by the operator.

The tool does not access data of any other YouTube user, and does not collect viewer data, analytics, contacts or payment information.

How data is used and stored

  • Data is used solely to upload and describe the operator's own videos.
  • OAuth tokens are stored only on the operator's personal computer and are never transmitted to any server other than Google's APIs.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy.

Revoking access and deletion

Access can be revoked at any time at Google Account → Third-party access. Revoking access and deleting the local token files removes all data held by the tool. Stored tokens are deleted within 30 days after they are no longer needed.
